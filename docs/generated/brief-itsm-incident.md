### Fields — critical vs useful vs optional

**Critical** (get these wrong and the module misbehaves; mandatory-ness varies by instance):

- `number` — Auto-number; the only identifier users quote. Never edit by hand.
- `caller_id` — Who is affected. Wrong caller = wrong SLA, wrong comms, wrong reports.
- `short_description` — Mandatory by dictionary on OOB; the searchable summary.
- `assignment_group` — Routing. If this is empty, nothing else you configure will get the ticket worked.
- `state` — Drives SLA pause/resume, close rules, and reporting. Changing state order breaks automation.
- `impact + urgency` — These compute priority. Priority is usually derived, not typed.
- `close_code + close_notes` — Enforced at close by OOB UI policy; blank closes corrupt reporting.

**Useful:** category / subcategory, `cmdb_ci`, `assigned_to`, short_description vs description hygiene, u_* custom fields only when a report demands it

**Optional / nice to have:** `location`, `department`, caused_by (problem), `parent_incident`, knowledge (linked article)

**Related lists worth configuring:** Task SLA, Incidents (child/related), Affected CIs, `Approvers`, Work notes / Additional comments

## Must know (the 5 facts that unlock the rest)

- incident extends task. Everything you learn about 'task' fields applies to incident, problem, change, and catalog tasks.
- Priority = f(impact, urgency) through a matrix (Data Lookup), not something agents type.
- An SLA is a task_sla record attached to the incident; the SLA definition decides start/pause/stop conditions.
- Closing requires close_code + close_notes in OOB; that is a UI policy, so it is invisible in the dictionary.

## Common mistakes

- Adding a custom field when an unused OOB field already exists.
- Editing state choices without checking SLA and flow conditions that reference state values.
- Testing as admin only — admin bypasses ACLs, so 'it works' means nothing.
- Making assignment_group optional 'to go faster', which silently orphans tickets.
- Deleting demo users, which breaks OOB flow references.
