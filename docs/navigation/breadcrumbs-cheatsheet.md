## Common Tables

| Table Name | What It Stores | Common Fields |
|------------|---------------|---------------|
| `incident` | Incident records | `number`, `short_description`, `state`, `priority`, `assignment_group` |
| `problem` | Problem records | `number`, `short_description`, `state`, `root_cause` |
| `change_request` | Change records | `number`, `short_description`, `state`, `risk`, `implementation_date` |
| `cmdb_ci` | Configuration Items | `name`, `ip_address`, `os`, `manufacturer`, `model` |
| `em_event` | Events | `node`, `source`, `type`, `severity`, `message` |
| `sn_hr_core_case` | HR Cases | `number`, `short_description`, `state`, `category`, `employee` |
| `risk` | GRC Risks | `risk_category`, `likelihood`, `impact`, `risk_score` |
| `policy` | GRC Policies | `name`, `description`, `owner`, `review_date` |
| `u_*` | Custom tables | Varies by customization |
