# Lab Steps: Remote Table

**Time:** 30-40 minutes  

---

## Step 1: Create Data Source
**Breadcrumb:** System Import Sets → Administration → Data Sources → New

| Field | Value | Notes |
|-------|-------|-------|
| Name | `JSONPlaceholder_Users` | Descriptive name |
| Type | `REST` | We're pulling from REST API |
| Import request method | `GET` | Retrieving data |

Click **Submit**.

Open the Data Source and configure:
- **REST Endpoint:** `https://jsonplaceholder.typicode.com/users`
- **Authentication type:** `No authentication` (for this lab)
- **Format:** JSON (should be auto-detected)

Click **Update**.

---

## Step 2: Create Remote Table
**Breadcrumb:** System Definition → Tables → New

Select **Create a remote table** (or look for "Remote table" option)

| Field | Value | Notes |
|-------|-------|-------|
| Label | `External Users (Remote)` | Display name |
| Name | `u_external_users_remote` | Table name (will be auto-generated) |
| Data source | `JSONPlaceholder_Users` | Select the data source we just created |
| Accessible from | All application scopes or your scope | As preferred |

Click **Submit**.

---

## Step 3: Define Fields/Mapping
After creating the Remote Table, you'll need to define which fields from the JSON to display.

Look for **Columns/Fields** related list or configuration on the Remote Table record.

Map relevant fields:
- `id` → maybe as a key/identifier
- `name` → display
- `email` → display
- `username` → display

**Note:** Field mapping depends on your instance version. Look for "Field Map" or configure columns to match JSON structure.

---

## Step 4: Test the Remote Table
**Breadcrumb:** Go to Application Navigator → search for your table label `External Users (Remote)`

Open the list view. You should see records pulled live from the JSONPlaceholder API showing user data.

**If empty:**
- Check Data Source test/connection
- Check field mappings
- Look at System Logs for errors
- Verify endpoint is accessible

---

## Step 5: Verify It's Truly Remote
Open a record from the remote table. Notice:
- Data comes from external source
- Changes you make here typically don't write back to external source (read-only in most cases)
- Refreshing shows live data

This confirms it's a view into external data, not a copied table.

---

## Key Breadcrumbs
- Data Sources: `System Import Sets → Administration → Data Sources`
- Remote Tables: `System Definition → Tables` (create remote table)
- View data: Application Navigator → [Your Remote Table Name]
