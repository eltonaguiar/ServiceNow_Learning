## Troubleshooting

| Issue | Check | Fix |
|-------|-------|-----|
| **No records appear** | Data Source config, field mapping | Verify endpoint returns JSON array. Check field mappings match JSON keys. |
| **Authentication errors** | Auth type/credentials | For public APIs use No Auth. Check if API needs headers. |
| **Connection timeout** | Network/MID Server | Public APIs usually work without MID. Check instance network restrictions. |
| **Wrong data structure** | JSON format | JSONPlaceholder returns array at root - ensure configured for array response. |
| **Permission issues** | ACLs/Roles | Need rights to create tables/data sources. Use admin in dev. |
