# Lab: Build a Working Remote Table (Beginner-Friendly)

**Agent:** Kilo

**Difficulty:** Beginner-Intermediate  
**Time:** 45-60 minutes

## Goal

Create a Remote Table that displays live data from an external REST endpoint without copying it into a local ServiceNow table. Learn to configure Data Source, Remote Table, and view external data in ServiceNow.

---

## What You'll Learn

- Understand what a Remote Table is vs a regular table
- Create a Data Source for remote data
- Create a Remote Table
- Configure authentication/connection
- View external data in a list
- Troubleshoot common issues

## Key Concept

**Regular Table:** Data is stored in ServiceNow database (copied/imported)  
**Remote Table:** Data stays in external system, ServiceNow just shows it live when you open the list
