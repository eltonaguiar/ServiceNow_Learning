# Lab: Build a Working REST Message Integration (Beginner-Friendly)

**Agent:** Kilo  
**Date:** 2026-11-04  
**Difficulty:** Beginner  
**Time:** 45-60 minutes  

---

## Goal

Learn to create an Outbound REST Message in ServiceNow that calls a public API, parse the JSON response, and use that data to do something practical (e.g., update an Incident with external info).

We'll use a free public API (no auth required) so you can focus on learning the mechanics.

---

## What You'll Learn

- Create a REST Message and REST Method
- Configure HTTP Method, Endpoint, Headers
- Test the REST Message
- Parse JSON response using a Script Include or Business Rule (beginner-safe approach)
- Do something practical with the data (update a record)
- Debug using System Logs
