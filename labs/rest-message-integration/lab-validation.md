## Troubleshooting

| Issue | Check | Fix |
|-------|-------|-----|
| **REST test fails with connection error** | Network/proxy/MID Server | For public APIs usually no MID needed. Try different network or check instance connectivity. |
| **401/403** | Auth/headers | Add authentication if API requires it. Check headers. |
| **Business Rule doesn't run** | Active? Conditions? Timing? | Make sure Active is checked. Check filter conditions. Try "before insert/update" or "async". |
| **Work notes not updated** | Script errors | Check System Logs for errors. Check gs.info messages. |
| **JSON parse error** | Response format | Look at actual response body in logs. Check Content-Type. |
| **Permission denied** | Roles | Need rights to create REST Messages/Business Rules. Use admin in dev instance. |
